# AI-RWA Portfolio Optimizer - Design System

## Brand Colors
- **Background**: #0a0a1a (深色科技感)
- **Foreground**: #ffffff (白色文字)
- **Accent**: #667eea (紫色渐变)
- **Accent Secondary**: #764ba2 (紫色辅助)
- **Success**: #4caf50 (绿色)
- **Warning**: #ff9800 (橙色)

## Typography
- **Headline**: Inter, sans-serif, 700-900 weight
- **Body**: Inter, sans-serif, 300-400 weight
- **Code**: JetBrains Mono, monospace

## Style
- **Mood**: Tech / Futuristic
- **Palette**: Dark / Premium
- **Energy**: Medium (corporate, SaaS, explainer)

## Visual Elements
- 渐变背景
- 发光效果
- 卡片式布局
- 动态数据展示
